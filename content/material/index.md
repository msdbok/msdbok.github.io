# Materials

Study aids that accompany the lectures: a summary of each session, questions to test
yourself against it, and the case descriptions used in the on-campus sessions.

- [Study Notes](notes.html) — one page per lecture, summarising what it argued and linking to the handbook page beneath it.
- [Revision Questions](questions.html) — lecture and reading questions for each area, with no published answers.
- [Case Materials](cases.html) — system descriptions and assignment briefs for the case sessions.

## Course books

- **Roger S. Pressman**, *Software Engineering: A Practitioner's Approach*. McGraw-Hill, 2005.
- **Frank Tsui, Orlando Karam, Barbara Bernal**, *Essentials of Software Engineering*. Jones & Bartlett Learning, 2022.

Every other source is cited where it is used. Each content page ends with a **References**
section listing exactly the works that page cites, generated from the site bibliography — so
a paper's details are always read from the page that relies on it rather than from a
hand-copied list here, which is how the previous version of this page came to carry a wrong
publisher and a truncated entry.
